## Description

```markdown
Make a Calendar Studio is an offline-first Linux desktop workspace for designing
printable calendars and planning date-driven work.

Create monthly and yearly grids; save local projects; count business days around
US federal holidays; plan payroll dates and rotating shifts; compare 4-4-5,
4-5-4, and 5-4-4 fiscal periods; convert dates; and export vector PDF/SVG,
CSV, JSON, or ICS data.

**Private by default:** calendars and projects stay on your device. The core app
works offline; optional web resources open in your browser only when selected.

**Related Make a Calendar resources**
* Make a Calendar: https://make-a-calendar.com/
* Printable monthly calendars: https://make-a-calendar.com/monthly-calendars
* Blank calendar templates: https://make-a-calendar.com/pages/blank-calendar
* Calendar generator: https://make-a-calendar.com/calendar-generator
* Multi-month calendars: https://make-a-calendar.com/multi-month-calendar
* Business-day calculator: https://make-a-calendar.com/business-days-calculator
* Pay-period calendar: https://make-a-calendar.com/pay-period-calendar
* Rotating-shift calendar: https://make-a-calendar.com/shift-calendar
* Fiscal calendar: https://make-a-calendar.com/fiscal-calendar
* 4-4-5 calendar: https://make-a-calendar.com/445-calendar
* 4-5-4 calendar: https://make-a-calendar.com/454-calendar
* 5-4-4 calendar: https://make-a-calendar.com/544-calendar
* Date tools: https://make-a-calendar.com/date-tools
* Date converters: https://make-a-calendar.com/converters
* iCalendar generator: https://make-a-calendar.com/ical-generator

This independent, original desktop application is created by Ethan, the
developer behind Make a Calendar. It is not the website packaged in a browser
and does not use the website's private implementation.
```
